NewsstandRSS

RSS and Atom magazines on the Newsstand shelf of jailbroken iOS 6.

Add this source in Cydia https://aurelioochoa.github.io/newsstandrss/repo/
  1. Open Cydia and go to Sources → Edit → Add.
  2. Enter the address above and tap Add Source.
  3. Open the NewsstandRSS source, select NewsstandRSS, and tap Install.
  4. Restart SpringBoard when prompted, open Newsstand, and tap + RSS to add a feed.
Requires iOS 6. Cydia installs the required dependencies automatically. If the source cannot load on stock iOS 6, install TLS Fix (com.skyglow.tlsfix) from http://cydia.skyglow.es/ first, as with the TorchLock source.
